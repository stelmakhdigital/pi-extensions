# Данные: графики, оси, форматирование, состояния

## Выбор типа по вопросу

| Что нужно узнать | Тип | Минимум условий, чтобы тип работал |
|---|---|---|
| Тренд, форма изменения | линейный | ≥ 5 точек, известна единица, серии сопоставимы |
| Сравнение величин между собой | бары | ≤ 12 категорий, иначе топ-N + «прочее» |
| Ранжирование | горизонтальные бары, отсортированные | подписи влезают без поворота |
| Доля целого | stacked bar или таблица долей | ≤ 5 сегментов; pie только на 2-3 |
| Часть от целого, одна цифра | ring/прогресс с числом внутри | одно значение, не сравнение |
| Распределение | гистограмма, box plot | ≥ 30 наблюдений |
| Зависимость | scatter | ≥ 20 точек, есть смысл в корреляции |
| Изменение во времени по категориям | small multiples, а не 6 серий на одном поле | 2-4 серии на поле |
| Тепловая карта величин | heatmap с легендой-шкалой | ось категории × ось времени |

Если тип графика не выводится из вопроса — на экране лишний график, а не недостающий.

## Оси и сетка

- Линейная шкала по умолчанию. Логарифмическая — только с подписью «шкала логарифмическая».
- Частоты, доли и деньги: ноль на шкале. Обрезка без подписи искажает сравнение.
- Сетка горизонтальная, светлая, не чаще 5 линий; вертикальная сетка по точкам времени не нужна.
- Подписи оси Y в тех же единицах, что и заголовок, один раз: `₽ млн`, а не `1 000 000 000`.
- Временная ось: интервал между метками кратный данным (сутки/неделя/месяц), последняя точка подписана, если она важна.
- Подписи осей контрастны 4.5:1 и не меньше 11-12 px: экономия на подписях отнимает у графика смысл.

## Форматтеры

```js
const nf = (opts) => new Intl.NumberFormat("ru-RU", opts);
const money = (v) => nf({ style: "currency", currency: "RUB", maximumFractionDigits: 0 }).format(v);
const num = (v) => nf({ maximumFractionDigits: 0 }).format(v);            // 1 284 903
const pct = (v) => nf({ style: "percent", maximumFractionDigits: 1 }).format(v);
const compact = (v) => nf({ notation: "compact", maximumFractionDigits: 1 }).format(v);  // 1,3 млн
const date = (d) => new Intl.DateTimeFormat("ru-RU", { day: "2-digit", month: "short" }).format(d);
const delta = (v) => `${v > 0 ? "+" : v < 0 ? "−" : "±"}${pct(Math.abs(v))}`;  // знак и направление текстом
```

- Разделители тысяч и десятичное знака — по локали пользователя, а не хардкодом.
- Единица измерения один раз на блок: в заголовке карточки или в подписи оси.
- В таблице точное значение; компакт — в заголовках и на осях.
- Дельта: направление текстом и знаком, цвет как усиление. Для скринридера: `<span aria-hidden="true">▲</span><span class="sr-only">рост на</span> 12%`.
- Пропуск — `—` с подсказкой или `нет данных`, но не `0` и не пустая ячейка: пустая читается как ноль.
- Дата с таймзоной, если данные из разных зон: `14:03 MSK`.

## Responsive SVG без библиотек

```html
<svg viewBox="0 0 600 240" preserveAspectRatio="none" role="img" aria-labelledby="chart-title">
  <title id="chart-title">Выручка по неделям, ₽ млн</title>
  <g class="grid">…</g>
  <polyline class="series" points="…" fill="none" stroke="currentColor" stroke-width="2" vector-effect="non-scaling-stroke" />
</svg>
```

- `viewBox` + `width:100%`; толщина линии через `vector-effect: non-scaling-stroke`, иначе на мобильном линия жирная или тонкая.
- Подписи осей не масштабировать вместе с полотном: рисовать их отдельным слоем с фиксированным кеглем либо опускать часть меток при узком вьюпорте.
- `role="img"` + `<title>` — иначе скринридер объявляет безымянную картинку. Если график несёт данные, рядом обязательна таблица-альтернатива (`<table class="sr-only">` или раскрывающийся блок «данные графика»).
- Точки, на которые можно навестись, доступны с клавиатуры: `tabindex="0"` на маркере либо управление «←/→ по точкам» с объявлением значения в `aria-live`.

## Вырожденные данные: названное поведение

| Случай | Что делаем |
|---|---|
| 0 строк в таблице | Блок «пусто»: почему пусто и что сделать (изменить период, импортировать). Скелетон не показывать. |
| 1 точка на графике | Точка + число, линия не рисуется; подпись «недостаточно данных для тренда». |
| Все нули | Шкала не сжимается до одной линии: фиксированный диапазон 0-1 с подписью. |
| Отрицательные значения | Нулевая линия явная и подписанная, области ниже нуля не красить в «ошибку» без причины. |
| Один спайк на порядок выше остальных | Ось не растягивать до спайка: клиппинг с маркером «пик N вне шкалы» или log-шкала с подписью. |
| Пропуск в середине ряда | Разрыв линии, а не прямая через дыру; подсказка «данных за 12.03 нет». |
| Нет прав на значения | `—` с подсказкой; график либо без этой серии, либо с явной подписью «часть данных скрыта». |
| Значения расходятся в двух источниках | Показывать источник и время среза у цифры, а не самое удобное число. |

## Состояния загрузки

- Скелетон повторяет геометрию итогового блока (те же высоты и ширины) — иначе каждая загрузка даёт CLS, это видно в `perf.mjs`.
- Частичная загрузка хуже честной ошибки: блок, где пришла половина рядов, обязан сказать об этом.
- Повтор ошибки — кнопкой с тем же действием и сохранёнными фильтрами, а не перезагрузкой страницы.
- Таблица на тысячи строк: виртуализация или страница по 50-100 с «показано X из Y» и счётчиком, который не врёт при фильтре.

## Проверка глазами

- Первый вопрос «где главное» решается за один взгляд; если для этого нужно сканировать 12 карточек — иерархия не собрана.
- Все ли числа в колонке в одном формате; все ли отрицательные видны как отрицательные.
- Легенда рядом с полем, а не сверху через весь экран; порядок серий в легенде равен порядку на графике.
- При 375px: один-два показателя и таблица вместо шести графиков; ничего не режется, горизонтальный скролл только у корпуса таблицы.
