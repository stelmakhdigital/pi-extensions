# Session Insights

Анализ прошлых pi-сессий → отчёт с рекомендациями → черновики улучшений.
Всё read-only по файлам сессий; скрипты — Python 3 stdlib, без зависимостей.

## Шаги

### 1. Собрать digest

```bash
python3 ~/.pi/agent/skills/session-insights/scripts/insights.py [фильтры]
```

Фильтры: `--since 30d`, `--until`, `--cwd <подстрока>` (повторяемо), `--min-cost`,
`--errors-only`, `--top N`, `--json`.
По умолчанию бери `--since 30d`. Если сессий мало или пользователь указал проект —
расширь окно до `--since 90d` / добавь `--cwd`.

В digest: стоимость по сессиям, ошибки инструментов + ретраи, максимальные объёмы
tool output, повторяющиеся строки промптов, повторная инъекция длинного контекста,
частые слова-темы.

### 2. При необходимости — детали

- Конкретная сессия (посмотреть, где именно были ошибки/ретраи):
  ```bash
  python3 - <<'EOF'
  import sys; sys.path.insert(0, __import__('os').path.expanduser('~/.pi/agent/skills/session-insights/scripts'))
  import sessions as S, glob, os
  for p in S.iter_session_files():
      s = S.summarize_session(p)
      if s and s.short_id == 'XXXXXXXX':  # id из digest
          print(s.path); print('errors:', s.errors_by_tool, 'retries:', s.retries)
  EOF
  ```
  Или просто `read` нужного `.jsonl` с offset/limit (файлы JSONL, ищи `"isError": true`).

### 3. Интерпретация → рекомендации

Прочитай digest и выведи рекомендации, каждая с **обоснованием из данных**
(число из digest) и **типом улучшения**:

| Паттерн в digest | Тип улучшения |
|---|---|
| строка из промптов повторяется ≥3x (поправка, правило) | Правило в AGENTS.md / CLAUDE.md проекта |
| длинный блок контекста инжектится ≥2x | Скилл или prompt-snippet (автоподстановка) |
| ошибки одного инструмента в ≥3 сессиях, ретраи | Экстеншн-инструмент / guard (аналог bash-guard) |
| максимальный tool output > 50k символов | Триггер усечения в экстеншене / в правиле AGENTS.md |
| тема (слово/фреймворк) в ≥5 сессиях без скилла | Новый скилл под эту тему |
| компактные дорогие сессии с высоким cacheWrite | Рекомендация по модели/длине контекста |

Не выдумывай: только то, что подкреплено строками digest.

### 4. Отчёт + черновики

Создай в **текущем** каталоге проекта:

```
.session-insights/
  report-<YYYYMMDD>.md    # отчёт: что нашлось, рекомендации с обоснованием
  drafts/                 # готовые черновики на проверку пользователю
    <имя>-SKILL.md        # новый скилл: frontmatter + SKILL.md
    agents-md-block.md    # блок текста для вставки в AGENTS.md
    <имя>-extension.ts    # каркас экстеншн-инструмента (TypeScript, pi API)
```

Требования к черновикам:
- Черновик скилла: frontmatter `name`/`description` + рабочие шаги, не вода.
- Блок для AGENTS.md: формулировки-правила (imperative), не описания.
- Каркас экстеншна: `import type { ExtensionAPI } from '@earendil-works/pi-coding-agent'`,
  зарегистрированный инструмент, TODO-комментарии на местах, где нужна логика.
  Смотри на `extensions/*/index.ts` этого репо как на эталон стиля.

В отчёте укажи, какой черновик закрывает какую рекомендацию.

### 5. Ответ пользователю

Кратко: 3–7 ключевых находок (с цифрами), список созданных черновиков с путями,
вопрос — что применять. Не пересказывай отчёт целиком.

## Ограничения

- Только чтение `~/.pi/agent/sessions`; никогда не модифицировать сессии.
- Субагентовские транскрипты учитываются (вложены в родительскую директорию).
- `cost` может быть 0 у локальных/кастомных провайдеров — тогда ориентируйся
  на токены и объёмы, не на деньги.
- Стоп-слова в `insights.py` базовые; если тематика узкая, фильтруй темы руками
  по разделу «Частые слова».
