Работай только в рабочем дереве: меняй файлы, запускай тесты и проверки. Git-операции (commit, push, tag, reset, clean, checkout веток) не выполняй — только по моей явной команде на каждую. В конце перечисли изменённые файлы и предложи готовый коммит (сообщение + список файлов), но не выполняй его.
