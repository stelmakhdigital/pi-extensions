Работай по скиллу ui-design (в списке скиллов; если не подхватился — /skill:ui-design). До вёрстки: 2-3 реальных референса, taste preflight (предмет, аудитория, настроение, движение, раскладка, якорь) и токен-план в DESIGN.md в корне проекта (если файл есть — читать его, палитру заново не изобретать). Не использовать центрированный hero с градиентом, сине-фиолетовые градиенты, три карточки с иконками в ряд, glassmorphism и emoji вместо иконок. План сверить с references/anti-patterns.md и изменить то, что совпало с дефолтом без причины. Верстать на данных в 2-3 раза длиннее ожидаемых, сдавать экран с lint-ui.mjs, a11y.mjs и скриншотами 375/768/1440.
