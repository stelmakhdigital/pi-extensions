Работай по скиллу ui-design (в списке скиллов; если не подхватился — /skill:ui-design). До вёрстки: 2-3 реальных референса с тем, что от каждого берёшь, и токен-план в DESIGN.md в корне проекта (если файл есть — читать его, палитру заново не изобретать). Не использовать центрированный hero с градиентом, сине-фиолетовые градиенты, три карточки с иконками в ряд, glassmorphism и emoji вместо иконок. Верстать на данных в 2-3 раза длиннее ожидаемых, сдавать экран со скриншотами 375/768/1440.
