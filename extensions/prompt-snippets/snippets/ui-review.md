Работай по скиллу ui-review (он в списке скиллов; если не подхватился — /skill:ui-review). Сначала шаг 1: lint-ui.mjs по исходникам и a11y.mjs по запущенному экрану, потом скриншоты и чеклист из references/checklist.md. Отдай только находки в формате путь:строка (или DOM-селектор с шириной) с тяжестью и конкретным исправлением, правила не пересказывай. Цифры (контраст, проценты, «нарушений нет») брать только из вывода скриптов; непроверенное помечать отдельно. Если проверяешь новый дизайн, сверь экран с DESIGN.md и со списком анти-шаблонов из ui-design.
