# Prompt Snippets

Комбинируемые одноцелевые промпт-правила, которые вставляются в сообщение
перед/после вашего текста при отправке. В отличие от skills, каждый сниппет —
крошечная самостоятельная инструкция: включайте ровно те, что нужны, на каждое
сообщение.

## Использование

- **alt+s** или **/snippets** — открыть меню переключения.
  - `↑`/`↓` — навигация, `space` — вкл/выкл, `enter` — применить, `esc` — отмена.
  - `tab` — предпросмотр выделенного сниппета (имя, placement, order, имя файла
    и полное тело; `↑`/`↓` прокручивают длинное тело). `tab` или `esc` — назад
    к списку, позиция курсора сохраняется.
  - Меню в рамке и прокручивается, когда список не помещается в экран (высота
    подстраивается под терминал), при обрезке — индикаторы `↑ ещё n` / `↓ ещё n`.
- Активные сниппеты видны виджетом над редактором:
  - `↑ в начало: ...` (цвет accent) — вставляется перед вашим сообщением
  - `↓ в конец: ...` (цвет warning) — вставляется после сообщения
- При отправке сообщения тела активных сниппентов объединяются с текстом:
  группа prepend (по `order`) → ваш текст → группа append (по `order`),
  разделены пустыми строками.
- Переключатели сбрасываются в **выключенное** состояние после каждой отправки
  и при старте сессии.

## Файлы сниппетов

Сниппеты лежат в `snippets/` рядом с `index.ts` — по одному markdown-файлу
с frontmatter:

```markdown
---
name: Concise
description: Держи ответы короткими и по делу
placement: prepend
order: 10
---
Отвечай кратко. Без вступлений и лишних объяснений.
```

| Поле | Обязательное | Примечание |
|---|---|---|
| `name` | нет | Отображаемое имя; по умолчанию — имя файла без `.md` |
| `description` | нет | Показывается рядом с именем в меню |
| `placement` | нет | `prepend` или `append` (по умолчанию: `append`) |
| `order` | нет | Число; сортировка внутри группы — в меню и в итоговом тексте (по умолчанию: `9999`, совпадения — по имени) |

Каталог сканируется при каждом открытии меню и каждой отправке сообщения,
поэтому изменения вступают в силу сразу — `/reload` не нужен.
