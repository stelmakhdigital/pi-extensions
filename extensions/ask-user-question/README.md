# ask-user-question (расширение pi)

Добавляет инструмент `ask_user_question`, которым агент задаёт пользователю
**ровно один вопрос** и приостанавливает выполнение до ответа.

## Режимы ввода

- **Свободный текст** — если варианты не заданы: открывается редактор,
  Enter — отправить, Esc — отменить.
- **Один вариант** — список вариантов + «Другое» (свой ответ).
- **Мультивыбор** (`multiSelect: true`) — несколько вариантов + «Другое»
  + пункт «Отправить» (Space — вкл/выкл, Enter по пункту — тоже переключение).

Во всех режимах Esc отменяет вопрос; модель получает структурированный
ответ (`status`, `question`, `mode`, `answers`) в `details`.

## Параметры инструмента

| Параметр | Тип | Описание |
|---|---|---|
| `question` | string | Единственный вопрос (один вопрос на вызов) |
| `details` | string? | Дополнительный контекст под вопросом |
| `options` | array? | Варианты `{ label, value?, description? }`; пусто — текстовый ввод |
| `multiSelect` | boolean? | Разрешить несколько ответов |

## Примечания

- Требует интерактивный режим (UI); в неинтерактивных сессиях возвращает
  статус `unavailable`.
- Всплывающие окна сериализуются общим мьютексом в `globalThis`
  (`__piSharedUiLock`), поэтому не конфликтуют с другими расширениями,
  использующими `ctx.ui.custom`/`editor` (например, bash-guard).
